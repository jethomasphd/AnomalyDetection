Every day, four independent detection methods analyze every domain's Google Postmaster spam rate. Each method asks a different question: "Feel the Rhythm" — did the pattern of spam reports change? "Feel the Rhyme" — is this something we've never seen before? "Get on Up" — do three independent statistical tests all agree something is off? "It's Bobsled Time" — is the spam rate accelerating upward? When multiple methods fire together, the signal escalates. Spikes (going up) trigger action. Dips (going down) are noted as good news. A domain at 0.2% that just doubled from 0.1% is more urgent than one stable at 0.4% — this system detects behavioral change, not just thresholds.

How This Works ▶

"Feel the Rhythm" — Fourier Transform

Detects structural changes in the spam rate's spectral signature. Catches slow shifts in how recipients perceive your email.

"Feel the Rhyme" — Matrix Profile

Asks: has this pattern ever happened before? Catches first-time events — spam traps, bad list sources, infrastructure changes.

"Get on Up" — Statistical Ensemble

Three independent tests (Z-Score, Seasonal Decomposition, Isolation Forest) each examine a different angle. When all three agree, it's real.

"It's Bobsled Time" — EWMA Trend

Tracks momentum. Is the spam rate accelerating upward? Decelerating? Breaking out?

Escalation Logic

WATCH 1 method, or a dip (good) → monitoring only HEADS UP pattern shifted → keep an eye on it ATTENTION unprecedented pattern → needs attention WARNING multiple methods agree → investigate URGENT clear upward momentum → act now CRITICAL previously warned, now worse → immediate action
