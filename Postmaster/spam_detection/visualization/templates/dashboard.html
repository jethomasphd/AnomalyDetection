How This Works ▶

Four independent detection methods run daily on every domain. When they agree, the signal escalates. Spikes (spam rate going UP) trigger action. Dips (spam rate going DOWN) are noted for awareness only.

"Feel the Rhythm" — Fourier Transform

Watches the natural rhythm of spam reports. When the spectral signature changes structurally, it fires.

Catches: Slow, structural shifts in audience perception of your email.

"Feel the Rhyme" — Matrix Profile

Asks: "Has the spam rate ever done this before?" If the current pattern has no historical match, it's novel.

Catches: First-time events — spam traps, bad list sources, infrastructure changes.

"Get on Up" — Statistical Ensemble

Three independent tests (Z-Score, Seasonal Decomposition, Isolation Forest) each look from a different angle.

Catches: Multi-dimensional outliers that no single test would flag alone.

"It's Bobsled Time" — EWMA Trend

Tracks spam rate momentum. Accelerating? Decelerating? Breaking out?

Catches: Sustained trends that build over days — the sled is moving.

Alert Escalation

WATCH "Peace Be the Journey" — 1 test flagged, or a dip (good). Monitoring only. HEADS UP "Feel the Rhythm" — Pattern shifted. Keep an eye on it. ATTENTION "Feel the Rhyme" — Unprecedented. Needs attention. WARNING "Get on Up" — Multiple tests agree. Investigate. URGENT "It's Bobsled Time" — Clear upward momentum. Act now. CRITICAL "Sanka, Ya Dead?" — Previously warned, ignored. Now worse.

Google Spam Rate Thresholds

Below 0.10% — Healthy. 0.10 - 0.30% — Within tolerance. Monitor. 0.30 - 0.50% — Google is watching. 0.50 - 1.00% — Problem territory. Above 1.00% — Deliverability at risk. Above 3.00% — Critical.

Key insight: This system detects changes, not just thresholds. A stable 0.4% is less concerning than a 0.2% that just doubled from 0.1%.

What To Do When You Get an Alert ▶

Investigate in this order:

1. CHECK YOUR LISTS Did you add new recipients? Bad list = bad spam rate. 2. CHECK YOUR CONTENT Did email content change? Spam trigger words? 3. CHECK SEND FREQUENCY Sending more often? Too much = more complaints. 4. CHECK AUTHENTICATION SPF, DKIM, DMARC still passing? 5. CHECK INFRASTRUCTURE IP reputation, DNS, ESP platform issues.

Rule of thumb: One domain affected = list or content issue (1-2). Multiple domains = infrastructure (5).
