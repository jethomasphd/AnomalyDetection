How detection works

Four independent statistical methods analyze each stock. When multiple methods agree, confidence is high. Diamond markers on charts show where anomalies were detected.

Fourier Transform

"Has the rhythm of this stock changed?"

Decomposes price into frequency components. When the pattern shifts (e.g., choppy to trending), it flags a structural change.

Matrix Profile

"Is this stock doing something it's never done?"

Searches all historical subsequences for a match. If no similar pattern exists, the behavior is truly novel.

Statistical Ensemble

"Do multiple stats tests agree it's unusual?"

Combines Z-score outlier detection (40%), seasonal decomposition (30%), and Isolation Forest ML (30%).

EWMA Trend

"Is this stock's momentum abnormal?"

Tracks deviation from the exponential moving average and classifies trajectory: normal, accelerating, decelerating, or breakout.
