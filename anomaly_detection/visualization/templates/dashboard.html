How It Works

This system uses four independent statistical methods to detect anomalies. When multiple methods agree, we have higher confidence something unusual is happening.

Fourier Transform

"Has the rhythm of this stock changed?"

Analyzes the frequency spectrum of price movements. When trading patterns shift (e.g., from choppy to trending), it signals a structural change.

Matrix Profile

"Is this stock doing something it's never done?"

Finds the most similar historical subsequence for each recent window. If no good match exists, the current pattern is truly novel.

Statistical Ensemble

"Do multiple statistical tests agree it's unusual?"

Combines Z-score outlier detection (40%), seasonal decomposition residuals (30%), and Isolation Forest machine learning (30%) into one score.

EWMA Trend Analysis

"Is this stock's momentum abnormal?"

Tracks deviation from the exponentially weighted moving average and classifies the trajectory as normal, accelerating, decelerating, or breakout.
