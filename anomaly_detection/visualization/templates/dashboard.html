Trading Signals

Confidence = how many methods agree: Strong (3-4), Moderate (2), Developing (1). These signals are NOT financial advice — they're what the data is saying.
Fourier Transform
Decomposes price into frequency components using FFT. Detects when the stock's cyclical pattern shifts from its historical baseline via KL divergence of spectral energy distributions. Answers: "Has the stock's rhythm fundamentally changed?"
Matrix Profile
For every recent 10-day window, finds the best historical match. If even the best match is poor, the pattern is genuinely novel. Uses the STUMPY library. Answers: "Is this stock doing something it has never done?"
Statistical Ensemble
Combines three independent tests: Z-score (40%) measures standard deviations from mean, Seasonal decomposition (30%) isolates residuals after removing trend/seasonality, Isolation Forest ML (30%) detects multivariate outliers. Answers: "Do independent statistical tests agree?"
EWMA Trend
Measures deviation from the 20-day exponentially weighted moving average. Classifies trajectory: breakout (>80% of range), accelerating (slope >0.02), decelerating, or normal. Answers: "Is the current momentum abnormal?"

How Signals Are Derived

Four independent detection methods analyze each stock daily. When anomalies are detected, they're translated into actionable signals. No single method controls the outcome — consensus is the signal.

  • Buy / Sell — mean-reversion: price extended from trend, momentum fading
  • Long / Short — momentum: breakout with accelerating force
  • Reduce — regime change: both Fourier and Matrix Profile flag structural shift
  • Watch — anomaly detected but awaiting directional confirmation

Confidence: Strong (3-4 methods agree), Moderate (2), Developing (1 with high score).

Technical Details

1. Fourier Transform — Frequency-Domain Structural Change

Decomposes price into frequency components. When energy distribution shifts from baseline:

D(local, baseline) = 0.5 * Σ [ local * log(local/baseline) + baseline * log(baseline/local) ]

2. Matrix Profile — Subsequence Novelty Detection

For every 10-day window, finds the best historical match. If poor → genuinely novel pattern.

3. Statistical Ensemble

ensemble = 0.4 * zscore + 0.3 * seasonal_residual + 0.3 * isolation_forest

4. EWMA Trend — Momentum Deviation

Classifies trajectory: breakout (>80% range), accelerating (slope >0.02), decelerating, normal.

Consensus

consensus = 0.20*fourier + 0.25*matrix_profile + 0.30*ensemble + 0.25*ewma

Flagged when 2+ methods agree OR consensus exceeds the 97.5th percentile.
